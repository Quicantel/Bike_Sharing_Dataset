# 🚲 Bike Sharing Data Analytics Dashboard

## Deskripsi

Proyek ini merupakan dashboard interaktif yang dibuat menggunakan Streamlit untuk menganalisis data penyewaan sepeda (Bike Sharing Dataset). Dashboard ini menampilkan visualisasi data terkait tren penyewaan sepeda berdasarkan jam sibuk operasional dan pengaruh cuaca/suhu terhadap jumlah pengguna.

## Setup Environment

Pastikan Anda sudah berada di dalam direktori utama proyek ini (sejajar dengan file `requirements.txt`), lalu jalankan perintah berikut pada terminal:

```bash
pip install -r requirements.txt
```
